# P10 文本风格指标观察器

> 用套话词表和句长变异系数做启发式观察，不输出生成概率。

在线页面：[https://yuuqq.github.io/P10-aigc-detector/](https://yuuqq.github.io/P10-aigc-detector/)

返回工具箱：[新闻实验工具](https://yuuqq.github.io/P00-dashboard/)

## 教学使用说明

本工具是《新闻传播AI应用教程》配套页面，教材名称为「文本风格指标观察器」。页面只呈现两件已经写在脚本里的事：固定套话表的命中疏密，以及句子长度的变异系数。它不是语言模型困惑度，也不给出生成概率。

**适合对象**：新闻传播专业学生、媒体从业者

**课前准备**：准备一段约 300 字的文章。页面打开即可使用，计算在浏览器内完成。

**课堂里可以这样用**

1. 点「载入套话示例」和「载入叙述示例」，对照套话密度、句长起伏和句子高亮。
2. 再贴入自己的文本，点「看套话和句长」。
3. 讨论：词表没命中，为什么不能当成“人写的”证据。

数据边界以附录 A 为准：能在本机完成的计算不主动外发；示例数据仅供课堂；本工具输出不得单独当作结论。
